Included:
- index.html — public homepage
- dashboard.html — inquiry dashboard prototype
- styles.css / dashboard.css — styling
- app.js / dashboard.js — navigation + prototype inquiry handling
- assets/ — C.O.S.M.O. logo and privacy-safe program photos

IMPORTANT ABOUT THE INQUIRY SYSTEM
This first version uses the browser's localStorage so the form and dashboard can be tested immediately without a server. That means:
- inquiries are stored only in the browser/device where they were submitted;
- it is NOT the final production storage system;
- it is NOT suitable yet for a public live site.

For the real live version, connect the form and dashboard to a secure backend (recommended: Supabase) with authentication and Row Level Security. Then inquiries can be viewed securely from any device and email notifications can be added.

PRIVACY
Only photos where youth are not readily identifiable were selected for this version. Do not add identifiable youth photos or certificate names to a public site unless the appropriate permissions/releases are confirmed or identifying information is obscured.
